Every link above is live. The source for all five is one repository,
**[kim-nejudne/portfolio](https://github.com/kim-nejudne/portfolio)**, a directory
each.

All of it is self-hosted on a single droplet behind nginx. No PaaS, no serverless:
containers for the projects with a server, static files for the ones without, and
a push to `main` deploys whichever project it touches.

None of it was typed from a blank file, and the case studies say so plainly.
PokéTrack began as an AI-generated scaffold and was then taken apart: real
authentication, a real data layer, accessibility rebuilt, performance measured
against a budget. ts-dojo, Buzzr and Sketchy were built by an AI coding agent
against a written spec, one feature at a time, with every gap in the spec logged
as a decision and the product calls left to me. What the case studies are about
is the distance from that start to what is running now.

The eye behind the art directions is an editorial one, out of magazine and
desktop-publishing work that predates the nine years of JavaScript, and the
motion holds 60fps everywhere it appears.
